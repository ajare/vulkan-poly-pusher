# Vulkan Poly Pusher

A Vulkan renderer preserving Massive Poly Pusher's client-facing rendering concepts and authored resources.

## Language

**Comparison scene**:
A milestone's shared test scene, loadable in both a Massive Poly Pusher client and the equivalent Vulkan Poly Pusher client to verify the delivered rendering capabilities.
_Avoid_: Vulkan-only test scene, reference screenshot (an observation of a scene, not the scene itself)

**Legacy pipeline**:
The authored legacy rendering workflow supported by Massive Poly Pusher, retained as a supported workflow in Vulkan Poly Pusher. It does not mean retaining the OpenGL backend.
_Avoid_: OpenGL compatibility layer
